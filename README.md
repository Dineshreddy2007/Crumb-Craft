# CrumbCraft SRS Project Archive

This ZIP archive contains the complete **CrumbCraft — Artisanal Cake Studio & Festival Demand Planner** web application along with its Software Requirements Specification (SRS).

## Included Files
- `index.html` — Main CrumbCraft web application (`crumbcraft_without_page_color_customizer.html`).
- `crumbcraft_without_page_color_customizer.html` — Original uploaded HTML source file.
- `SRS_CrumbCraft_Project.md` — Comprehensive Software Requirements Specification (SRS) document.
- `README.md` — Project overview and usage instructions.

## How to Run
1. Extract the ZIP archive to any folder.
2. Open `index.html` (or `crumbcraft_without_page_color_customizer.html`) in any modern web browser (Chrome, Edge, Firefox, Safari).
3. Use the top navigation bar to switch between **Customer Pre-Order**, **Baker Capacity & BOM**, and **Login / Account** (with one-click demo credentials).
